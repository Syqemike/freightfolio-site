Programs

Classes

Adult Brazilian Jiu-Jitsu classes, youth Brazilian Jiu-Jitsu classes, and a free trial class for beginners.

Adult BJJ Classes

Adult classes cover the core of Brazilian Jiu-Jitsu: positions, escapes, submissions, and live training. Beginners start with fundamentals and build from there.

  • Gi and nogi training
  • Fundamentals for new students
  • Live rolling for those who are ready
  • Structured sessions, run on time

Youth BJJ Classes

The youth program teaches kids real Brazilian Jiu-Jitsu technique in a structured setting. Classes open and close the way martial arts classes should, with attention and respect.

  • Technique taught in plain language kids retain
  • Drilling partners, not chaos
  • Discipline and listening built into every class

Free Trial Class

If you have never trained before, the free trial class is the way in. You will see a full session, meet the team, and get a straight answer about whether the program fits.

  • One full class, no cost
  • Wear comfortable athletic clothes
  • Call ahead so the team expects you
