An inclusive yoga studio

Myriad Yoga is an inclusive yoga studio in Indianapolis and a sister operation to Myriad Fitness and CrossFit in the same building. Its classes include Vinyasa Flow, Aerial Yoga, a Yoga Foundations beginners class on Monday from 5:15 to 6:15 PM, and a free donation-based class on Sunday from 9:00 to 10:00 AM. The own site is a thin single page of class descriptions with no prices or online booking, so call or email with questions about a class.
